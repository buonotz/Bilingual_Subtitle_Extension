# Chrome Web Store listing — English

## Name

Streaming Bilingual Subtitles BETA

## Summary

Display a second official subtitle track on Netflix and Max web players.

## Detailed description

THIS EXTENSION IS FOR BETA TESTING.

Streaming Bilingual Subtitles displays two official subtitle languages at the
same time on supported Netflix and Max videos.

Keep one subtitle selected in the streaming player, open the extension, and
manually choose a second language from the official subtitle tracks available
for the current title.

Features:

- Two official subtitle tracks displayed together
- Netflix and Max web player support
- Fullscreen support
- Subtitle languages limited to those available for the current title
- Interface localized in English and Simplified Chinese
- No translation service, account registration, advertising, or analytics

The available languages depend on the title, account, and region. The extension
does not bypass subscriptions, authentication, DRM, or regional restrictions.

When a second language is selected, Chrome shows a temporary debugging
notification. This permission is used only to read the selected official
subtitle response in the current tab. Subtitle data is processed locally and is
not sent to the developer.

not affiliated with or endorsed by either service.
